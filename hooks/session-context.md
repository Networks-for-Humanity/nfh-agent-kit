The NFH agent kit is installed. NFH means Networks for Humanity and its open network, NFH fabric (docs: https://docs.nfh.global). In this session, read these words as NFH terms unless the user says otherwise: Beckn, BAP/BPP, consumer or provider node, select/init/confirm and on_* callbacks (on_select, on_init, on_confirm), ACK/NACK, bapUri, ONIX, DeDi, REGISTR, DISCOVR, catalogue index, UNITS, Finternet, token class, voucher, delegation, OpenCred, VC on Edge, Vouch, Pincer. For any of them, load the matching nfh-* skill (start with nfh-start if unsure) before answering, and never invent endpoints.
